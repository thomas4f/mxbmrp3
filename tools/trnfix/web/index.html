What is actually wrong

When the file is saved. MX Bikes sets aside room for the bike's name, the name does not fill it, and the game never clears the rest. Whatever was in memory at that moment gets written into your file. This does not happen on every save, and it looks more likely when other plugins are loaded.

When the file is loaded. The game reads that space back and treats it as text. Usually it is harmless. Sometimes it points somewhere that does not exist, and the game crashes or hangs on the loading screen. The same file can load fine one launch and fail the next.

So the damage is already in the file. Removing plugins does not undo it: damaged trainers have crashed with none loaded at all. No plugin reads or writes these files, only the game does. This is an MX Bikes bug and only PiBoSo can fix it properly. This tool just clears the leftover bytes back out.
